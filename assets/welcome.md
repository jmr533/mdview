# mdview

A fast, lightweight Markdown viewer.

**[Open a Markdown file…](mdview:open)** &nbsp; <kbd>Ctrl</kbd>+<kbd>O</kbd>

You can also drop a file onto this window, or run `mdview README.md` (or `mdview some/folder`) from a terminal.

## Keyboard

| Action | Keys |
|---|---|
| Open file | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Find in document | <kbd>Ctrl</kbd>+<kbd>F</kbd> or <kbd>/</kbd>, then <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Outline | <kbd>F9</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> |
| Theme (system / light / dark) | <kbd>Ctrl</kbd>+<kbd>T</kbd> |
| Zoom | <kbd>Ctrl</kbd>+<kbd>+</kbd> · <kbd>Ctrl</kbd>+<kbd>-</kbd> · <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| Back / forward | <kbd>Alt</kbd>+<kbd>←</kbd> · <kbd>Alt</kbd>+<kbd>→</kbd> |
| Reload | <kbd>Ctrl</kbd>+<kbd>R</kbd> |
| Quit | <kbd>Ctrl</kbd>+<kbd>Q</kbd> |

> [!TIP]
> Files reload automatically when they change on disk, so you can keep mdview open next to your editor.
